ShapePlay 3D – Lokal Mac Uygulaması (Shap-E + Mesh Düzenleme)

1) Amaç (PM’e özet)

“Yaz/Resim → 3D model üretip, aynı uygulama içinde törpüleme (düzenleme) + isimlik tabanı + yazı ekleme yapayım.
Hepsi MacBook’umda, internet gerekmeden, tek tıkla çalışan GUI + CLI ile çalışsın.
Çıktılar: GIF önizleme, OBJ/PLY/opsiyonel GLB/STL, ZIP paket.”

⸻

2) Kullanıcı Akışı (2 ekran)

A. Üretim (Shap-E)
	1.	Prompt yaz (max 500 karakter, sayaçlı) veya tek görsel yükle (PNG/JPG, max 5 MB).
	2.	“Oluştur” → Shap-E çalışır → GIF + OBJ/PLY(+GLB) üretir.
	3.	İndir: OBJ, PLY, GLB, GIF, ZIP.

B. Düzenleme (Blender headless + trimesh/open3d)
	1.	Model seç (son üretimler listesi / dışarıdan OBJ/PLY yükle).
	2.	İki yol
	•	Prompt’la hızlı komut: “kaide ekle 50mm”, “içi boşalt 1.6mm”, “delik 5mm”.
	•	Manuel araçlar: Scale, Rotate, Translate, Boolean (delik/kütle), Hollow/Thickness, Slice/Split, Smooth/Decimate, Yazı ekle, İsimlik tabanı ekle, Auto-repair.
	3.	Önizleme (3D viewer) + Undo/Redo + Önce/Sonra.
	4.	İndir: OBJ/PLY/GLB/STL + ZIP.

⸻

3) Teknik Sınırlar (UI tasarımına girecek)
	•	Prompt: serbest metin, maks 500 karakter (sayaç zorunlu).
	•	Görsel: tek dosya, PNG/JPG, max 5 MB (yüklemede kontrol).
	•	Shap-E: tek işlemde 1 prompt / 1 görsel.
	•	Çalışma süresi: 30–120 sn (bekleme animasyonu + iptal butonu).
	•	Çıktı formatları: OBJ/PLY zorunlu, GLB/GIF opsiyon, STL düzenleme sonrası.

⸻

6) GUI – Ekran Tasarım Notları

Üretim Ekranı
	•	Prompt textarea (500 limit + sayaç)
	•	“Resim yükle” (drag&drop + buton)
	•	“Oluştur” + loading bar + “İptal”
	•	Önizleme (GIF)
	•	İndir butonları: OBJ, PLY, GLB, GIF, ZIP
	•	Hata durumları: uzun prompt, büyük görsel, desteklenmeyen format

Düzenleme Ekranı
	•	Model seçici (galeri/list) + “Dışarıdan yükle”
	•	Hızlı komut (prompt) kutusu (200 karakter)
	•	Araç paleti (ikon + yan panel parametreleri):
	•	Transform (Scale/Rotate/Translate)
	•	Boolean (Add/Cut → küp/silindir/küre; çap/yükseklik/konum)
	•	Hollow/Thickness (mm)
	•	Slice/Split (düzlem seç, parça sayısı)
	•	Smooth/Decimate (hedef face sayısı %)
	•	Yazı Ekle: metin (≤30 karakter), font, kalınlık (mm), yükseklik (mm), konum (üst/alt/yan/manüel XYZ), Kabartma/Oyma
	•	İsimlik Tabanı Ekle: şekil (daire/kare/üçgen/altıgen/dikdörtgen/oval), otomatik boyut (objeye göre %120) veya manuel mm, kalınlık, yazı (metin + font + kabartma/oyma, otomatik ortalama)
	•	Auto-repair (manifold, normal, self-intersection)
	•	3D Viewer (orbit/pan/zoom) + Önce/Sonra + Undo/Redo
	•	İndir: OBJ/PLY/GLB/STL, ZIP

⸻

7) CLI Örnekleri (Typer)

# Prompt'tan üret
shapeplay gen --prompt "kırmızı-siyah maskeli bir büst" --out ./output/run1

# Görselden üret
shapeplay gen --image ./in/ref.png --out ./output/run2

# Düzenleme: kaide ekle + içini boşalt + STL al
shapeplay edit --in ./output/run1/model.obj \
  --add-base shape=circle diameter=50 height=6 \
  --hollow wall=1.6 \
  --export stl --out ./output/run1_edit


⸻

8) Önemli Teknik Ayrıntılar
	•	MPS etkin PyTorch: Apple Silicon GPU hızlanması için PYTORCH_ENABLE_MPS_FALLBACK=1.
	•	Blender headless çağrısı:
blender --background --python mesh_ops/blender_scripts/add_base.py -- model.obj --shape circle --diameter 50 --height 6
	•	GIF üretimi: üç açıdan render (Shap-E veya Blender viewport) → imageio.mimsave.
	•	Auto-repair: önce trimesh.repair hızlı deneme; başarısızsa Blender’da derin onarım.
	•	STL sadece düzenleme aşamasında (yüzey sağlığı kontrolünden sonra) üretilir.
	•	Log/Sürüm: her işleme metadata.json (prompt, seed, parametreler, zaman, sürüm).
	•	ZIP: tüm çıktı + metadata + küçük önizleme görselleri.

10) Görev Kırılımı (ekibe atama)

A. Çekirdek – Shap-E entegrasyonu (2–3 iş günü)
	•	prompt/görsel → mesh + gif pipeline
	•	MPS hızlandırma + hata yönetimi
	•	GLB opsiyonel export

B. Mesh Ops – Blender headless scriptleri (4–6 iş günü)
	•	add_base / add_text / boolean / hollow / slice / repair / decimate
	•	parametre sözleşmesi (mm/derece) + test mesh’leri
	•	STL export ve doğrulama

C. GUI – PySide6 (5–7 iş günü)
	•	Üretim ekranı + Düzenleme ekranı
	•	3D viewer (QtWebEngine + three.js)
	•	Undo/Redo + Önce/Sonra
	•	İndirme/ZIP ve hata mesajları

D. CLI – Typer (1–2 iş günü)
	•	gen ve edit komutları, parametreler
	•	Ortak çıktı dizin yapısı + metadata.json

E. Paketleme & Dokümantasyon (1–2 iş günü)
	•	README (kurulum, kullanım)
	•	PyInstaller ile Mac app (opsiyonel)
	•	Örnek veri + “Hızlı Başlangıç”

Toplam ilk sürüm (MVP) tahmini: ~2–3 hafta (tek ekip, paralel çalışmayla daha kısa).
